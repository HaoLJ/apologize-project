# 💖 Romantic Apology Page (浪漫道歉页面)

这是一个专为向老婆表达歉意而设计的温馨互动页面。通过可爱的视觉效果和有趣的交互，传达真挚的歉意和爱意。

## ✨ 核心功能 (Features)

*   **🌸 浪漫氛围**：全屏粉色渐变背景，搭配漂浮的爱心动画，营造温馨感。
*   **🥺 真挚道歉**：诚恳的道歉文案，可自定义修改。
*   **🎉 "原谅我"特效**：点击"原谅我"按钮，触发全屏彩色纸屑庆祝动画，并显示"爱你"的成功反馈。
*   **😈 "不原谅"彩蛋**：点击"不原谅"按钮时，按钮会机智地躲避鼠标，并显示撒娇文案（如"再想想？"、"求求你了"），增加趣味互动。
*   **📱 响应式设计**：完美适配电脑和手机屏幕。

## 🛠️ 技术栈 (Tech Stack)

*   [React](https://reactjs.org/)
*   [Vite](https://vitejs.dev/)
*   [Tailwind CSS](https://tailwindcss.com/)
*   [Framer Motion](https://www.framer.com/motion/) (动画效果)
*   [canvas-confetti](https://www.npmjs.com/package/canvas-confetti) (撒花特效)

## 🚀 快速开始 (Getting Started)

### 本地运行

1.  安装依赖：
    ```bash
    npm install
    ```

2.  启动开发服务器：
    ```bash
    npm run dev
    ```

3.  在浏览器打开 `http://localhost:3000`。

### 局域网访问（给老婆看）

确保电脑和手机连接同一个 WiFi，启动服务后，查看终端显示的 Network 地址（如 `http://192.168.x.x:3000`），发给老婆即可访问。

## 📦 部署 (Deployment)

推荐使用 [Vercel](https://vercel.com) 进行免费部署，可生成永久访问链接。

1.  将代码提交到 GitHub。
2.  在 Vercel 中导入项目。
3.  点击 Deploy 即可。
